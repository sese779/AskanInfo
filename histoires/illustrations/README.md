# Illustrations IA (Askan Histoires)

Images fixes générées par IA pour les plans sans photo d'archive, dans le style
« cinéma réaliste ». Règles :
- **Jamais une personne réelle** (ni Mamadou Dia, ni Senghor, ni aucun guide religieux) :
  décors, lieux, objets, foules ou personnages anonymes vus de dos ou de loin.
- Pas de texte dans l'image (le texte est ajouté par `histoire.py`).
- À l'écran, le crédit devient « Illustration IA · scène reconstituée » : dans
  `photos/credits.json`, mettre la valeur `"IA"` pour ce nom de fichier.
- Rangement : `photos/<nom>.jpg`, format vertical 9:16 (1080×1920 ou plus).
- Étiquette « contenu généré par l'IA » cochée sur TikTok, Instagram et YouTube.
